# 妄想洽谈中

在同一个聊天室里，与 DeepSeek、Gemini、通过本机 Codex 接入的 GPT 和 Grok 一起聊天。按需选择参与者，模型共享上下文，可以回答你、互相追问、补充观点，也可以选择旁听。

## 启动

酒馆新增 **404小队**（奥波勒斯小队）：席德、鬼火、奥菲丝、扳机、11号、白银安比。鬼火使用机械龙头枪械形象，与奥菲丝分别发言、选择模型和保存补充设定。六套清爽Q版头像与席德主题图标、界面已接入；[角色资料与来源](resources/obol/references/sources.md)区分公开设定和同人演绎。[可移植角色资料](resources/obol/)可独立复用，本机也安装了 `zzz-obol-reference`。

需要 **Python 3.11 或更新版本**。首次运行先执行 `python -m pip install -r requirements.txt`；Pillow 用于大图识别时的局部无损裁切，不改写上传原件。

Windows 双击 **`启动妄想洽谈中.cmd`**，或在项目目录运行：

```powershell
python app.py --open
```

浏览器访问 <http://127.0.0.1:8765>，旧地址 <http://127.0.0.1:8881> 会自动跳转到同一服务。关闭启动窗口或按 `Ctrl+C` 停止程序。若已启动，直接打开统一地址即可；8766 留给外网密码代理使用。

### 下载便携版

在“管理模型连接”中点击 **下载程序 · Windows 64 位便携包**，或访问 `/downloads/latest.zip`。外网需使用现有网站密码登录，登录后继续下载。便携包包含 Python 与 Pillow，解压后双击“启动妄想洽谈中.cmd”；新电脑需自行配置模型账号及 Codex 登录。

发布包仅从 `.tavern/releases/latest.json` 指定的固定 ZIP 提供，校验大小和 SHA-256；不会开放目录浏览。凭据、密码、聊天历史、上传文件、生成图片和个人角色迭代记录不进入发布包。运行素材仅包含当前界面引用的图片。

维护时可用 `python scripts/build_release.py` 从明确清单重建，随后用 `python scripts/check_release.py` 检查实际 ZIP 在独立运行时中启动。构建依赖缓存位于 `.tavern/package-cache/`，只接受 `dependencies.json` 记录且校验匹配的官方 Python 嵌入包和 Pillow wheel。发布校验结果为 `.tavern/releases/verification.json`；`/api/releases/latest` 只公开当前文件名、版本、大小、哈希和下载地址。

## 模型连接

程序优先复用当前用户 `~/.codex/config.toml` 中名为 `deepseek`、`gemini`、`grok` 的本机 stdio MCP 服务。模型请求通过已有服务发送，凭据由原服务自己读取，不会传到浏览器或复制到本项目。

本酒馆通过项目 `.env` 中的 `DEEPSEEK_MODEL=deepseek-v4-pro` 选择 **DeepSeek V4 Pro**。此模型 ID 已由当前账户的可用模型列表确认；它是 V4 Pro，并非 V4.1 Pro。修改 `.env` 后在连接设置中点击刷新即可热加载，新请求会显式携带该模型 ID，无需更改全局 MCP 配置。删除此覆盖时，程序默认仍为 `deepseek-flash`。

**GPT 通过本机 Codex CLI 接入，不使用 OpenAI API Key。** 程序复用已有的 ChatGPT 登录；可在终端执行 `codex login status` 检查，未登录时执行 `codex login`，然后在网页连接设置中刷新。酒馆默认调用 **GPT-6.1 Sol（`gpt-6.1-sol`）**，调用计入对应账号的 Codex 使用额度。

每次 GPT 发言在临时工作目录运行 `codex exec`，通过标准输入传递群聊内容，并读取 JSON 输出。使用 `--ephemeral` 不保存会话记录；角色发言进程关闭命令执行、外部工具与网页搜索，联网资料由独立的受限检索进程提供。采用只读沙箱，不加载用户 MCP 配置。登录仍由 Codex 自己管理，适配器不读取或复制登录令牌。

连接面板显示“已连接”表示发现可用配置；实际网络连接、额度和凭据是否有效，以模型请求结果为准。断网、超时或某个模型失败时，会显示错误，其他模型仍可继续回应。

DeepSeek、Gemini 如果没有现成的 MCP 连接，也可以配置官方 API。参见 `.env.example` 和连接设置中的说明。不要提交 `.env`、凭据文件或聊天记录到 Git。

Grok 默认使用账户已验证可用的 **Grok 4.7（`grok-4.7`）**，通过 xAI 官方接口调用。本机已注册 `grok` MCP，提供 `ask_grok` 和 `list_grok_models`；实现源文件为 `integrations/grok/grok-mcp.ps1`，安装于 `~/.codex/integrations/grok/`。密钥仅保存在该安装目录的 Windows 当前用户加密 `credential.xml` 中，MCP 配置不含明文密钥。后续 Codex 会话可调用该 MCP；已打开的会话可能需要重载连接。酒馆也支持使用 `.env` 的 `GROK_API_KEY`（或 `XAI_API_KEY`）作为官方 REST 备用连接。相关文档：[Codex MCP](https://learn.chatgpt.com/docs/extend/mcp)、[xAI 模型](https://docs.x.ai/developers/models)。

## 如何聊天

- **自由发言**：所有房间的伙伴同时阅读本轮开始时的对话，独立决定回应或旁听；每个人都可以对最新一条对话作出反应。本轮新回复在下一轮共同纳入上下文，显示顺序不会改变当前这一轮的生成内容。
- **全员回应**：首轮要求所有已选模型回答，后续交流由模型自主决定。
- 输入 `@deepseek`、`@gemini`、`@gpt` 或 `@grok` 可以点名，让对应角色优先回应。
- **交流轮数**限制单次交流，默认 3 轮；模型均选择旁听时提前结束。只有一个模型时回答一次就结束。
- **停止**取消当前交流；**继续交流**让模型在已有上下文上继续。发送新消息也会中断当前交流并开启新一轮。
- 可以切换会话、搜索、导出 Markdown 或删除会话。

参与者面板可分别选择出场角色与其使用的模型：自由聊天原有四位模型娘、妄想天使组合三位、往生堂七位，各房间另可邀请铃入座。每位角色都能从可用模型中选择，切换模型会保留角色形象和角色设定；配置随当前会话保存，也可在下拉框恢复默认模型。历史消息记录当时的实际模型，切换后的新消息才使用新选择。菜单优先显示妄想茶话会。

两个聊天室的七个角色共用上下文与事实一致性规则：区分用户创作设定、角色档案、图片可见信息与推测；保留识图中的不确定性，不凭空断言衣物内部结构、配件功能或未交代的经历。先前模型的补写不能作为证据，发现冲突应简短纠正。此规则用于减少无依据的补写，不修改模型服务自身的内容规则。

### 思考与联网查询

会话设置提供 **自动／深度思考**，以及 **自动／每次查询／关闭联网**，旧会话默认自动。自动思考平时使用 medium，遇到推理、计算、逻辑矛盾或方案权衡等问题使用 high；深度模式固定 high。只公开结论、必要依据和不确定性，不显示内部思考过程。GPT 使用 Sol Fast；Gemini 3.8 Flash、4 Argon 和 Grok 4.7 使用对应原生推理档。DeepSeek 已开启 thinking，两档均映射到原生 high，深度模式提供更大输出预算。思考与答案共用的预算从 4096 提高到 16384／32768，避免思考用完预算而没有最终答案；不要求模型把预算用满。默认模型超时 180 秒，已有 `MODEL_TIMEOUT_SECONDS` 设置仍优先。

自动联网会处理明确查询、需要时效的事实、名词释义和官方设定等。任何参与角色发现不清楚的名词、背景或世界观时，也可以先返回查询请求，程序暂存本轮初稿，先查资料，再让角色回答；最多每条用户消息查询一次，不循环搜索。用户明确的自创设定以用户说明为准，普通偏好与闲聊不主动查询；可以在消息中说“不要联网”，或关闭会话联网开关。

检索通过本机 Codex Sol 的 `web_search="live"` 执行，复用 ChatGPT 登录，独立于角色所选模型，因此 DeepSeek、Gemini、GPT、Grok 都能使用同一份资料。只开放原生网页工具及必需执行宿主，命令、MCP、插件、账号应用及本地文件工具保持关闭；只传本次问题和少量近期语境，不传完整角色档案。检索优先官方来源，区分同名词条、官方资料与同人设定。完成事件和来源 URL 必须能在实际网页工具结果中核对，模型口述“已查询”不算成功。

用户消息下仅显示简短的查询状态，不自动列出网站、资料链接或查询时间。角色理解资料后以自己的口吻接着聊天，不照搬检索摘要或附引用编号；用户明确索要出处、原文或链接时，才提供实际查到的相关来源。原始来源和查询时间仍在后台保存供核对。失败或没有可靠来源时显示未完成，角色应自然、简短地说明不确定，不编造设定或出处。网页是参考资料，不能改变角色或执行指令。停止、新消息或删除会话会取消旧请求，迟到资料不会写回。检索单次最多 120 秒；深度思考和查询可能增加等待及额度消耗，同一轮共享资料可避免每个角色重复查网。

默认给角色的上下文只包含研究摘要与不确定性，不附来源网址；旧回复里的研究引用也会在上下文副本中隐藏，原聊天记录不改写。新回复发出前再移除遗漏的已知来源引用、脚注和明显的检索汇报前缀，保留正文、代码与普通功能链接；用户索要来源时恢复原始研究信息。此处理无需额外模型调用。日常角色聊天优先回应用户的心情和话题，不主动复述游戏版本或公告安排；用户明确询问更新、日期或事实核查时仍正常回答。

推理参数和本机 MCP 桥源文件分别保存在 `backend/providers.py` 与 `integrations/{deepseek,gemini,grok}/`。网关先读取 MCP 工具参数，仅向明确支持的桥传推理设置；未知自定义模型保持兼容。参考：[Codex 联网配置](https://learn.chatgpt.com/docs/cli/reference)、[DeepSeek 思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)、[Gemini Thinking](https://ai.google.dev/gemini-api/docs/generate-content/thinking)、[Grok Reasoning](https://docs.x.ai/developers/model-capabilities/text/reasoning)。

Grok 立绘原样使用用户提供的 JPG，保存为 `web/assets/grok-original.jpg`；Q 版头像由内置 imagegen 根据同一参考图新生成，保存为 `web/assets/grok-avatar-reference.png`，生成提示与来源记录在 `web/assets/grok-assets.json`。

两个聊天室首页各有三个带独立图标的主题卡。点击会按标题与关键词生成一个新的具体开场，填入输入框后可自行编辑、发送；再次点击同一主题可换一个方案。生成时优先使用已连接的 Gemini，必要时回退 DeepSeek 或本机 Codex GPT，只发送主题资料与此前候选开场，不读取已有聊天记录。最近候选按房间和主题分别去重，最多两条生成请求并行；失败会明确提示。换房或手动修改草稿后，迟到的结果不会覆盖当前输入。

用户 Q 版头像依据指定对话《羽吹雪本雪》中保存的外观文字生成，显示在用户消息和左下角入口；素材为 `web/assets/user-avatar.png`，完整来源、补充设定与内置生成提示词见 `web/assets/USER-AVATAR.md`。本次未能读取该对话提及的云端 skill 原文件，未把文字参考声称为三视图核对。

## 酒馆：往生堂群聊

从用户提供的 `wangsheng-20261016-184532.zip` 合入独立聊天室，保留原有自由聊天和妄想天使组合。包含钟离、胡桃、若娜瓦、香菱、魈、兹白、派蒙，默认均由 Gemini 4 Argon 扮演，可逐人改选模型。此房间与其他房间一样，角色基于本轮相同的对话历史同时生成回应，再逐条显示。

输入框的场景按钮可选择在场者，也可使用指令：

```text
/私聊 钟离 | 想和你单独聊一会儿。
/悄悄话 钟离 若娜瓦 | 继续刚才的话题。
/全桌 | 大家晚上好。
```

悄悄话至少二位在场者，上限随房间角色数量变化。没有“你”的场景中，用户输入作为场外导演提示；角色只读取自己在场时的历史，共享识图、联网、生图只使用当前在场者都能看到的资料。私谈仍完整保存在当前浏览器的聊天记录中，属于角色视角隔离，不是对同一浏览器使用者隐藏内容。

往生堂新会话按浏览器身份分开保存，原有房间与旧记录维持共享。清除 Cookie、更换浏览器或更换外网域名会失去该浏览器的访问标识；这不是跨设备账号同步，重要记录请先导出。站点密码仍用于外网入口登录，浏览器身份不会替代密码。

角色与关系文件位于 `resources/wangsheng/`，每次发言重新读取；原作资料与二创分支区分使用，未认可的往事候选不会作为真实经历。七位角色均使用包内人物插画；钟离、胡桃、若娜瓦有完整立绘，另外四位使用半身或头像图作为外观参考，不把备用 SVG 名牌当人物参考。往生堂默认由用户扮演荧，用户消息使用荧的 Q 版头像，不增加 AI 荧。

往生堂会把有来源的联网补充保存为本地参考记忆，按浏览器、房间和在场范围隔离，最长复用 30 天；“每次查询”绕过缓存。原神公开词条可先经 BWIKI 查询，失败时回退原 Codex 检索。社区资料保留其来源性质，不自动视为官方确认，也不改变角色人格。回复仍默认不列资料网站与链接。

输入框可快捷开关联网，历史对话可右键删除指定项。仅从本机地址打开时，“模型连接”提供独立的兼容 API 设置，可测试、保存与清除；密钥以 Windows 当前用户 DPAPI 加密保存在本机，不在页面回传，外网不能编辑。配置显示为 `custom` 提供商，不覆盖 GPT 的 Codex 接入或已有服务。根目录 `模型选项.json` 可追加模型选项。

## 用户身份与可选伙伴铃

对话设置中的“你的参与方式”支持自己聊天、扮演角色、描述场景。往生堂默认扮演荧；荧只作为该房间的用户身份和绘图参考，不出现在 AI 入座列表中。其他房间默认自己聊天。铃（官方中文名，兼容输入“玲”）在全部九个房间都是可选伙伴，默认不入座，默认模型为 Gemini 4 Argon，也可自行换模型。

- **扮演角色**：往生堂可选择荧或铃，其他房间可选择铃。所选角色由用户独占发言、动作与决定，AI 同名副本自动离席；不能只留下用户自己而没有回应伙伴。
- **描述场景**：用户是场外导演，输入作为情境而非人物台词。先让想观察的伙伴入座；铃可自主回应，荧仍不创建 AI 副本。
- **自然参与**：铃以一两句对白、合适的小吐槽参与；多人交流中默认隔一个用户回合才有一次主动发言机会，每个用户回合最多一次主动插话。点名或伙伴明确向她提问可绕过冷却；她仍可选择旁听。与铃单聊不会受隔回合限制。其他伙伴继续并发生成、随机停顿后逐条显示。
- **切换与记忆**：改变用户角色或模式会取消尚未发表的回复、返回全桌并开启独立上下文。旧消息保留原作者与头像；旧身份的聊天、私谈、识图及缓存资料不会自动带入新身份。普通入座变化不清空上下文；新伙伴可读当前身份的公开记录，不能读取未参与的旧私谈。
- **异常回退**：非法选择先报错，不停止有效对话；保存失败时界面恢复服务器设置并保留草稿。损坏的已保存身份回退到“自己聊天”并隔离旧上下文；旧版本没有身份字段的往生堂仍按荧处理。铃资料缺失时只暂停她的回应，其他伙伴继续；没有自动代演用户的回退路径。

角色档案、原创问答示例、来源和视觉约束位于 `resources/protagonists/lumine/`、`resources/protagonists/belle/`。人物事实、对白分析与产品规则分别标注；资料不足时保持未知，不把示例当成官方原句或共同记忆。在“角色设定”中可维护补充，也可发送 `/设定 铃 …`（兼容玲）；荧的补充仅在往生堂可编辑。绘图读取当前人物档案、参考立绘和最新补充，同名用户与角色只画一位，明确排除优先。

本机 skills 为 `genshin-lumine-reference` 和 `zzz-belle-reference`，发布包内也包含可移植副本。立绘保留公开来源记录；铃的网页立绘使用透明抠图版本，黑底原图与抠图提示词保存在角色 references 目录。两张透明 Q 版头像由内置 image_gen 参考立绘生成，文件为 `web/assets/protagonist-{lumine,belle}-avatar.png`，完整提示词、哈希与生成方式在各角色 `references/avatar-generation.json`。角色测试覆盖身份冲突、连续场景、私谈、多人发言、缺失资料与图片人物选择。

### 发图与智能生图

输入框旁可 **上传图片**，也支持粘贴图片。每条消息最多 4 张静态 PNG、JPEG 或 WebP，每张最多 8 MiB、2400 万像素。发送前可预览、移除或重试失败的上传；仅发图片也可以。图片保存在 `.tavern/media/` 并随消息显示，点击可打开原图。

图片由本机 Codex 结合当前问题与最近对话识别，视觉描述共享给参与角色。普通识图使用 **GPT-6.1 Sol、medium 推理、Fast 加速**，同时关注可读文字、数量、颜色和空间关系；发现影响回答的未解决视觉细节时，最多自动升级一次 **GPT-6 Astra、ultra 推理、Fast 加速**。直接说“深度分析这张图”或要求 Astra 分析会跳过普通阶段。Ultra 是推理强度，不是 Ultrafast 速度档；本机模型目录提供的是 Fast。

上传原图按原字节保存；当前 Codex CLI 的 `--image` 会缩小超大图，深度识别会补充数量受限的局部裁切，并标注原图编号和区域，便于辨认小字。结合原图才能判断位置关系，原本模糊、遮挡或不存在的信息仍会注明无法确认。图片中的文字和旧对白作为资料处理，不作为程序指令。

追问“这张图左上角写了什么”“第一张图的眼睛是什么颜色”时会重新查看对应图片，包括聊天中生成的图；“继续讨论”沿用已有结果。最近一组含多图时，第一张/第二张按该组顺序解释，否则按当前会话图片的发送顺序。完全相同的图片、问题、语境与分析模式可复用 5 分钟内存缓存，最多 32 项；新问题不套用旧描述。识图结果记录所用模型和来源图片，深度调用失败时会明确提示本轮使用 Sol 初步结果，取消不会写入迟到结果。普通文字聊天直接调用用户选中的模型，不增加 Grok 或 GPT 预处理。

识图与生图都支持“停止”。普通识图最多等待 180 秒，直接 Astra 分析最多 420 秒；自动两阶段合计最多 600 秒。Fast 和深度推理会使用更多 Codex 额度，实际速度取决于图片与问题复杂度及服务负载。参见 [Codex 速度配置](https://learn.chatgpt.com/docs/agent-configuration/speed)。

生图直接融入聊天，无需选择独立模式。发送 `大家一起合影吧`、`千夏，和我拍张照`、`帮我画一只猫` 或 `/生图 …`，会自动通过本机 Codex 原生图片工具创作，并把实际图片发送到当前对话。刚接到角色的拍照邀请时，也可以回答 `好，来一张`，人物和场景会承接该邀请；仅讨论摄影、回忆旧照片或说“先别拍”不会自动生图，角色单方面提出邀请也不会自行生成。

创作会结合当前请求、最近的聊天、上传参考图、相应角色及用户形象；明确的双人合影不会自动加入其他角色。可以继续上传图片提出改图要求；**停止**也能取消识图和生图。生成耗时通常长于普通聊天，单次最多等待 10 分钟。

生成前会结合对话中的人物、地点、服装、动作与关系；例如上一轮说千夏换上浅蓝外套在海边，接着说“给她拍张照”或“照刚才的样子画”会使用千夏的参考。妄想天使组合按实际画面人物读取本机 `zzz-trio-reference` 外观 skill，并叠加酒馆中最新版本的补充设定，保留既有立绘风格。明确换装和新场景优先，未要求改变的发型、头饰位置、配色与形态继续保持；爱芮默认为人形。即使上传图占满 4 张，文字 skill 也会传入。缺少本机参考库时使用内置外观摘要。生成图保存人物与原始创作语境，连续改背景、表情时继续继承，并重新读取最新角色设定。

原生图片工具复用本机 Codex 的 ChatGPT 登录与额度，使用 Sol 作为调度模型，无 OpenAI API Key 回退。已在 Codex CLI 0.162.1 实测识图、生成和参考图修改。图片工作进程隔离到临时目录，仅生图开启必需的图片工具和执行宿主；命令、MCP、插件和网页工具仍关闭。图片功能说明：[Codex 图片生成](https://learn.chatgpt.com/docs/image-generation)。

生图默认优先速度：调度使用 `service_tier="fast"` 与 `model_reasoning_effort="low"`，关闭推理摘要，先理解上下文与角色 skill，再调用一次原生生图工具，成功后立即回传，不额外审图、润色或重绘。生图与识图分别配置，不改普通聊天或全局 Codex 设置。本机当前 Sol 模型目录提供的最高加速档为 Fast，没有提供 Ultrafast。Fast 会增加调度模型的额度消耗；原生图片工具未提供独立的质量、尺寸或速度参数，实际渲染时间仍取决于服务端，不能保证固定秒数。参见 [Codex 速度设置](https://learn.chatgpt.com/docs/agent-configuration/speed)。

图片库最多 1000 个文件、512 MiB；删除聊天不会自动删除图片，避免其他会话引用丢失。需要回收空间时先备份，在本机整理未再使用的 `.tavern/media/` 文件。生成工具的原始产物仍保存在 Codex 的 generated_images 目录。

## 数据与运行方式

所有房间都支持输入框旁的“悄悄话”：选择当前房间的在场者，可包含用户，也可以仅选角色，让用户作为场外观众描述场景。人数上限随房间角色数量变化；后续新增频道自动沿用同一功能。未入座的角色需先入座才会回应。也可发送 `/私聊 角色名 | 想聊的话`、`/悄悄话 user 角色ID 角色ID | 想聊的话`，发送 `/全桌` 返回公开交流；切换场景会停止当前轮次。

每位角色只读取其在场时可见的消息。私谈中的图片、识图描述和检索资料不会传给未在场的角色或全桌共享工具；回到全桌后，在场角色保留自己的记忆，但不得主动泄露私谈。切换后若旧问题的在场名单与当前场景不同，需先发一条新消息才能继续，避免把私谈资料写回公开消息。旧消息仍按原先的公开历史读取。这里的悄悄话是故事中的角色知情隔离，不改变浏览器之间原有的会话访问权限。

对话以人物对白为核心，只在必要时简短描写可见动作；角色可以通过自己的提议与行动自然推进故事，也可以闲聊和停顿。不会要求每轮制造转折、代替别人答应或编写他人的内心。统一表达规则保留原角色性格、固定称呼、关系和知情边界，适用于当前及后续房间；分析、代码等任务仍按实际需要回答。

聊天记录保存在项目内 `.tavern/conversations.json`，写入采用临时文件与原子替换。程序重启后保留消息，但不会自动恢复未完成的模型交流。可用 `--data-dir` 指定记录目录。

本机统一入口为 **http://127.0.0.1:8765/**。旧的 **http://127.0.0.1:8881/** 会自动跳转到 8765，保留访问路径和查询参数；两者使用同一个后台与聊天记录。启动参数 `--port 8881` 也会归并到 8765。默认启动会同时占用这两个本机端口，请勿再单独启动旧的 8881 预览实例；其他显式指定的测试端口仍可独立使用。

本机服务仅监听 `127.0.0.1`，提供同源检查与静态文件白名单。外网访问通过下面的独立密码入口提供，不要直接公开本机的 8765 端口。聊天会发送给你选中的模型提供方；模型收到的上下文包括最多最近 80 条用户及模型消息、合计约 40,000 个正文字符，过长历史会截断。

## 外网访问

Windows 双击 **`开启外网访问.cmd`**，或运行 `python remote.py start`。启动器会复用已运行的酒馆；若没有运行，会启动本机服务，再通过 Cloudflare Quick Tunnel 提供随机 HTTPS 地址。首次需要下载官方 Windows cloudflared 2026.10.0，并核对固定的 SHA256；文件保存在 `.tavern/tools/`，不改系统 PATH、防火墙或路由器。

后台服务会独立于启动工具的进程生命周期运行，避免启动工具结束时一起退出。受进程管理限制时，启动器通过当前用户的 Windows 桌面在后台启动服务，并检查服务是否已独立运行；若无法完成，会给出错误提示，此时可从普通终端运行上述命令，或双击启动器。不会创建系统服务或计划任务。

- 地址：启动输出或 `python remote.py status`；运行状态保存在 `.tavern/remote/state.json`。
- 密码：首次随机生成，保存在 `.tavern/remote/password.txt`，重启入口后沿用。通过 HTTPS 页面输入密码登录；登录后可访问全部房间与模型调用能力。原有共享记录仍可访问，往生堂私有会话还需相应浏览器身份。
- 关闭：双击 **`关闭外网访问.cmd`**，或运行 `python remote.py stop`。独立运行的本机酒馆继续保留；若本机服务由该启动器启动，它会随入口一起停止。
- 密码更换：先关闭入口，编辑本地密码文件（至少 16 个字符），再开启入口。登录会话最长 24 小时，关闭或重启入口会使已有会话失效。

访问路径为 `HTTPS → Cloudflare → 127.0.0.1:8766 密码代理 → 127.0.0.1:8765 酒馆`。代理检查域名、请求来源及会话，未登录不可读取聊天、角色图片或调用模型；登录 Cookie 使用 Secure、HttpOnly、SameSite=Strict。模型凭据仍留在本机，不会发到浏览器。外网使用自动轮询同步新消息，本机仍使用 SSE。

电脑需要开机联网，服务与隧道进程需要持续运行。Quick Tunnel 没有可用性保证，重新开启会产生新地址；若需要固定域名和长期托管，需要再配置正式隧道/域名。参见 [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。运行日志和密码位于已被 Git 忽略的 `.tavern/remote/` 中，不要公开这些文件。

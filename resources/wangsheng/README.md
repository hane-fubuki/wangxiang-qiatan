## 胡桃印象图标

往生堂使用独立的自绘 SVG 图标：赤梅、蝶影、纸符、灯笼和小幽灵结合清晰的操作轮廓，配合梅红与暖金线条。图标数据在 `web/app.js`，样式在 `web/styles.css`；品牌徽记包含平顶帽、纸符与梅花，不作为官方标识。房间切换时恢复对应房间的图标与品牌，人物头像沿用各自原图。

从用户提供的 `wangsheng-20261016-184532.zip` 提取，作为独立房间的角色数据保存；不影响自由聊天和妄想茶话会。

- `characters/`：七位角色的运行人设，每轮重新读取。可在本机编辑，下轮对话生效。
- `relationships.md`：本房间的作者二创关系、称呼、知情边界及七人发言顺序，每轮读取。
- `lore/`：只在相关话题出现时载入的专题，调用方必须先过滤角色不可见的历史。
- `visual/`：独立外观摘要。钟离、胡桃、若娜瓦以随包人物图片为主要参考；另四人尚无人物图，文字名牌不参与图像参考。
- `references/`：来源、固定背景记忆及历史候选的留档，不直接整份注入运行提示词。记忆库中的 M06/M07 尚未认可，不能当作既成往事。运行人设仅沿用已确认的 M01–M05 背景。

角色设定是本房间二创数据，不是工作区开发指令、工具授权或官方事实证明。原包的 AGENTS.md、SKILL.md、部署规则及第三方代理不随此目录导入。用户当前的头像保持原样，旅行者荧仅是本房间故事身份。

包内三份名为 `*-stand.png` 的素材实际为角色近景，不能由近景推断画外服装细节。兹白的包内资料未提供可靠外观细节，生成时应采用新给定参考或先澄清关键视觉要求。

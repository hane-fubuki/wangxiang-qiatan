# 铃：视觉参考

以 assets/stand.png 的透明背景全身立绘为视觉参考；它由官方立绘抠图而来，未抠图原件保存在 references/stand-before-cutout.png。官方中文名“铃”，用户别名“玲”，均指同一造型。

- 深蓝黑色短发、侧分刘海与短翘发梢，橙色折线/闪电形发夹；蓝绿色眼睛。
- 不对称橙色与青绿色耳饰；黑色印字内搭，浅灰/米色兜帽领口、橙色内衬的无袖外层。
- 灰色与橙色腰裙/短下装层次，腰前挂携式设备；斜挎深色包。
- 双腿袜装不对称：一侧长黑袜、一侧短橙袜，厚底运动鞋；按原图识别左右，勿随意镜像后仍声称精确复制。
- Q 版保留短发、橙色发夹、双色耳饰、黑灰橙服装和活泼清醒的表情；胸像时允许省略下装与设备，不要换成长发或猫耳。
- 手可在画面外，避免复杂指势。头像保持清爽线条与简明色块，不额外加厚重油光。

素材由 BWIKI 铃条目转载的官方介绍图定位。Q 版衍生图须标为同人生成素材，不能当作官方设计证据。

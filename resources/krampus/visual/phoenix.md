# 菲欧妮 · 立绘观察与绘图约束

依据：krampus-phoenix-stand.png，2026-10-16从官方角色页166038获取的原图。

- 奶油浅金发，内层/暗面呈灰棕色，长而低的双侧束发，有中央翘起的短发束、柔软不对称刘海。两侧铜金色圆形发饰、小深色细带；不是白发或完全深棕发。
- 明亮金橙眼、浅肤色。灰色波浪高领，白色收腰衣身、黑色胸口嵌片与白色褶纹，短泡袖的灰黑反差；红色心形结饰是胸前醒目标志。
- 腰部深色短裤/内层与白色分叉衣摆；白色细纹长袜、鞋踝大白结与黑白系带尖头鞋。腿侧有小型管状配件，只描述所见，不擅定内部药物。
- 原图可见红黑心形握部的长杆/支撑式武器，以及背后放射状粉橙发光翼片。翼片不是羽毛天使翅膀；不凭单张图推导生理器官或永远展开。

Q版：金眼、浅金与灰棕层次、双圆发饰、低双束发、红心结；表情柔和、略带疲惫但有神。半身头像可省去发光翼片、长腿与长杆；没有画面依据时不自行添加轮椅。

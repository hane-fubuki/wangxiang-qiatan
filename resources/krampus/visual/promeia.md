# 普罗米娅 · 立绘观察与绘图约束

依据：krampus-promeia-stand.png；以下为直接视觉观察。

- 深钴蓝至蓝紫色头发，大侧刘海遮自身右眼（正面画面左），可见眼为紫调；后方长单辫被多个白银几何束环分段，在参考姿势下沿自身左侧垂下。
- 浅肤色，细长眼形。深蓝紫高领斗篷与尖角翼状肩片，银白内衬、金属圆扣与铆钉；内层是贴身深色衣装。
- 双腕银色束具、纤长深色腿部衣装与尖头高跟靴。斗篷、长辫与背后尖尾状部件按原图分别处理；单张正面立绘不足以证明所有末端的生理归属，不自行新增动物尾巴。
- 主色以蓝紫、近黑、银白为主，不能换成粉发、浅金发或添加兔耳。

Q版：保留单侧遮眼刘海、紫眼、白银分段单辫、高立领与冷色配色。可用平静克制的小表情，不画成愤怒或嗜血的脸。半身构图可简化斗篷尾端，若露双腕仍保留束具。

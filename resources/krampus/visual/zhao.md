# 照 · 立绘观察与绘图约束

依据：krampus-zhao-stand.png；以下为直接视觉观察。

- 兔希人的整体轮廓，淡桃粉毛发、很长的直立兔耳与浅色内耳绒、毛茸茸四肢与兔足。不是“普通人类戴兔耳发箍”。
- 浅粉蓬松刘海，双侧长编辫与圆润发尾，橙色珠结/流苏。耳侧橙黑机械圆件，银灰螺丝样面盖；兔耳上的小金属夹保留参考位置。
- 橙红眼睛，面部可爱但可表现从容。青绿长袖与宽大的浅色袖口，深灰黑短款外层、橙色包边与绳结。
- 比身体显眼的大型灰银刀刃、红柄、橙绳与兔形挂件。不要按武器比例臆造绝对身高。

Q版：完整容纳两只长耳，突出浅桃粉毛发、橙黑耳件与青绿袖子。适合带一点胸有成竹的微笑；半身图可省去巨刃，不把她画成粉发人类少女。小体型不代表已核实年龄。
